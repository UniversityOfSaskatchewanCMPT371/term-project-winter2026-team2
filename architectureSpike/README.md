Goal of this spike:

To implement a minigame in Unity VR to

- validate that MVC will be maintainable, and possible to write
- see what a folder hierarchy looks like
- check which supporting technologies + packages we need
- understand what the development process looks like (which files changed)
- understand how much time the project's goals will take

Results of this spike:

The spike does show that we can make the game. XR + XR Interaction
toolkit are the real godsends to us and are pretty much our one stop
shop for all things VR (and AR). These packages have all the sample
code that we can bootstrap from. A concern is the amount of time it
takes to achive anything with polish.
